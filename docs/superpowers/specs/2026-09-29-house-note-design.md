## 1. 目的と前提

### 1.1 目的
住宅購入（主に新築一戸建て・注文住宅）を検討する人が、**図を見るだけで「決めどころ」の要点をつかめる**一般公開の情報サイトを作る。同時に、制作者のポートフォリオとして見せられる完成度（デザイン・動き・コード品質）を持たせる。

### 1.2 ユーザーから確認済みの要件
| 項目 | 決定内容 |
|---|---|
| 位置づけ | 一般公開の情報サイト ＋ ポートフォリオ。「おしゃれなWebサイト」 |
| 表現 | 記事より図解中心。触って動く図／スクロールで展開する図／静止画インフォグラフィックの組み合わせ |
| テーマ（7章） | 01 住まいの選択肢と流れ／02 お金・資金計画／03 土地選び／04 土地×建物のトレードオフ／05 木造・鉄骨（構造）／06 住宅性能／07 住宅会社の選び方 |

### 1.3 仮定（ユーザー未否定のもの）
- 対象は日本の新築一戸建て。建売・マンションは01章で比較対象として扱う。
- 日本語のみ。ライトテーマのみ（ダークモードなし）。
- 章の並び順は上表の 01→07（全体像 → お金 → 土地 → 配分 → 構造 → 性能 → 依頼先）。

### 1.4 成功基準
1. 各章に v1 の図解が2点あり、図と1行キャプションだけで章の要点が伝わる。
2. サイトに載る数値はすべて出典と時点が表示されている。
3. スマホ幅（375px）でも全図解が操作・閲覧できる。
4. Lighthouse（モバイル）の Performance / Accessibility / Best Practices / SEO が各90以上。
5. GitHub Pages で公開され、URL で閲覧できる。

### 1.5 スコープ外
- 実在の住宅会社名・商品名の掲載、ランキング
- 個別の資金相談・投資助言、会員機能、問い合わせフォーム、CMS
- 多言語対応、ダークモード
- 年次の自動見直し・鮮度警告の仕組み（「検証は軽め」の決定による）
- 補助金の金額表示（仕組みの説明のみ）
- v2 候補の図解12点（4.3）と、批評で挙がった追加論点（団信、ペアローン、中古＋リノベ、火災保険の水災補償、境界確定、太陽光の費用と売電）。v1 では扱わない

### 2.4 事実データ（数値は必ずデータから引く）
- 図・本文に出す数値は直書きせず、`data/facts/*.yaml` から ID で参照する。
- Astro Content Collections（または同等の Zod スキーマ）で型を定義し、**出典（url・発行元）と時点（asOf）がない事実はビルドエラー**にする。存在しない ID の参照もビルドエラー。

```yaml
- id: flat35-2025-chumon-tochi-national-total   # 例
  claim: 土地付注文住宅の所要資金（全国平均）
  value: 0000
  unit: 万円
  asOf: 2025年度調査
  source:
    title: フラット35利用者調査
    publisher: 住宅金融支援機構
    url: https://...
    type: primary        # primary | secondary
  volatility: annual     # stable | annual | volatile（volatile は「○年○月時点」を自動表示）
  derived:               # 任意。当方算出の値のときだけ
    formula: 土地取得費 ÷ 所要資金
    from: [flat35-2025-..., flat35-2025-...]
  note: 任意
```
- 事実データの初期値は、別紙の「載せる事実」表で検証結果が C（確認済み）または Co（修正して採用）のものだけから作る。U（照合できず）は載せない。

## 3. 図解の表現ルール

### 3.1 3つの型の使い分け
| 型 | 使いどころ | 実装 |
|---|---|---|
| 触って動く図 | 読み手の条件で答えが変わるもの（予算配分、返済額、借入額） | Svelte コンポーネント、`client:visible` |
| スクロールで展開する図 | 順序・構造の理解（購入の流れ、骨組みの違い） | `.astro` ＋ GSAP ScrollTrigger（pin ＋ scrub） |
| 静止画インフォグラフィック | 一覧比較（住宅会社タイプ、性能等級） | `.astro` の SVG／HTML。JS 不要 |

### 3.2 見た目のルール
- 線は墨 1–1.5px、強調はテラコッタ1色、塗りは最小限（薄いハッチング程度）。
- どの図にも「この図のポイント」を1行、出典番号を付ける。
- 比較表は主観的な●評価を使わず、**根拠のある数値・事実だけ**で構成する。

### 3.3 動き（試作 v2 で合意した標準演出）
1. **分解アクソメ**：スクロールで画面固定し、部材が降りて線描されながら組み上がる（scrub、逆再生可）。未到達部分は薄い下書き線で表示。
2. **章扉**：章番号の輪郭線描＋見出しの一文字ずつのせり上がり。
3. **立体の触って動く図**：アイソメ図形をなめらかに補間し、数値をカウント表示。
4. **章遷移**：テラコッタの面が横切るワイプ。Astro View Transitions で実装。
- 大きな演出は1章1〜2か所の「見せ場」に絞る。

### 3.4 配慮（例外なく守る）
- `prefers-reduced-motion: reduce` では全演出をオフにし、完成形を表示。
- JS 無効時も完成形の SVG が表示される（プログレッシブエンハンスメント）。
- スライダーはネイティブ `input[type=range]`（キーボード操作可、タップ領域44px以上）。数値は常にテキストでも併記。
- SVG には `role="img"` と説明（`aria-label`/`<title>`）。動く図には同内容のテキスト要約を用意。
- 色だけに依存しない（線種・ラベルで区別）。文字コントラストは WCAG AA。
- スマホでは図を縦積みに再レイアウト。画面固定（pin）の長さはスマホで短縮。

### 3.5 パフォーマンス
- 島（islands）は `client:visible` で遅延読み込み。GSAP はスクロール図があるページだけで読み込む。
- フォントは Fontsource の unicode-range サブセットで配信し、`font-display: swap`。
- 目標：Lighthouse モバイル各90以上。

### 4.2 章をまたぐ実装ルール（批評 P0 の反映）
1. **日付ラベル**：`volatility: volatile` の値（金利・政策金利など）を表示する箇所には、必ず「YYYY年M月時点」を併記する。図に数値を焼き込まず、事実データから読み込む。
2. **法的な言い切りをしない**：建築条件付き土地の返還は「広告表示の義務。実際は契約書の特約で確認」、宅建業法の手付規制は「土地の売買部分は対象、建物の請負契約は対象外」、消費者契約法の説明は「請求の場面」に限定、など、別紙の修正済みの表現を使う。
3. **偏った母集団で優劣を示唆しない**：評価書データの工法別比率・業界団体調査（大手中心・営業担当者記入）を工法や業態の比較棒にしない。使う場合は全体値と母集団の注記に限る。
4. **調査が違う数値は同じ軸に並べない**：フラット35利用者調査と住宅市場動向調査は別パネルにし、定義の違い（例：総返済負担率と返済負担率）を明記する。
5. **当方算出バッジ**：出典の数値から当方が計算した値（坪単価換算、土地の割合、返済額など）には「当方算出」バッジを付け、計算式を開いて見られるようにする（`Fact` の `derived` 属性）。
6. **用語の一元化**：「平均と中央値」「総返済負担率／返済負担率」「延床面積／施工床面積」は用語集データにまとめ、各章から参照する。
7. **同じ数値の正本は1つ**：住宅ローン減税の限度額は02章の事実IDを正本とし、03・04・06章はその ID を参照する（別紙「章をまたぐ論点と重複の整理」に従う）。
8. **見せ場を重ねない**：分解アクソメは05章だけで使う。01章の時間軸では建物は立面シルエットが伸びる程度にとどめる。

## 5. 正確さの担保（軽量版）
- 数値はすべて事実データ経由（2.4）で、出典・時点を必須とする。
- サイト上では図の下に出典番号、章末に出典一覧を自動表示する。
- 金利など変動の激しい値は図に固定せず、「○年○月時点」付きの初期値としてユーザーが変更できるようにする。
- 事実の検証は、初回のコンテンツ調査時に行った照合の1回とする（150件を照合：確認済み122、修正して採用12、誤り0、照合できず16）。本番前の全数値再検証・年次見直しの仕組みは作らない。照合できなかった事実（別紙「要確認リスト」）はサイトに載せない。
- 補助金は金額を載せない（1.2）。住宅ローン減税は令和8年度改正で2030年入居分まで定まっているため金額も載せる。
- 免責：「一般的な情報であり個別の助言ではない」「最新情報は各公式サイトで確認を」「ローン試算は概算」。住宅会社タイプの記述は傾向と例外を併記する。
- 図・イラストはすべて自作。

## 6. テスト
| 対象 | 手段 | 合格基準 |
|---|---|---|
| 計算ロジック（`lib/`） | Vitest | 元利均等返済の既知値と一致（別紙の 4,000万円・35年で 0.8%→月約10.9万円、2.0%→約13.3万円、3.46%→約16.4万円）。機構の試算例（年収640万円・2.25%・35年で借りられる額 約5,422万円／返せる額 約2,614万円）を再現（丸めによる±1万円の差は許容。検算では 5,423万円・月18.67万円）。容積率の例（別紙 03章の A・B・C）を再現。境界値（金利0%、期間1年、容積率上限の切替点） |

## 8. エラー処理・フォールバック
| 事象 | 振る舞い |
